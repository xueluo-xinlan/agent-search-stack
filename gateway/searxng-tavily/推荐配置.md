# 推荐配置（2026-08-31 实测最优）

> 本套配置已在两台机器实测验证：**本机**（源码 + systemd，广东惠州电信 IP）与 **VPS**（docker，香港 IP）。
> 核心目标：解决出口 IP 信誉差导致的搜索质量低（bing/baidu/sogou 等对低信誉 IP 返回降级垃圾或反爬验证）。
> 核心手段：接入 **Tavily API 引擎**（走官方 API，不受出口 IP 信誉影响）+ 禁用低信誉引擎 + rerank 加权。

## 1. Tavily 引擎

- 官网：https://app.tavily.com（免费 1000 credits/月，**无需信用卡**）
- 计费：`basic` 深度 = 1 credit/次，`advanced` = 2 credit/次
- 引擎文件：本目录 `tavily.py`（来源 [searxng/searxng PR #6499](https://github.com/searxng/searxng/pull/6499)，AGPL-3.0）
- 优势：走官方 API，**不受出口 IP 信誉 / 反爬影响**，中文质量高（实测返回百度百科、央视、光明网等权威源）

**前置**：注册获取 API key（`tvly-` 开头），填入下方 settings.yml 的 `tavily.api_key`。

## 2. SearXNG 配置（searxng/settings.yml）

完整脱敏版，复制即用。填入真实 `api_key` 即可。

```yaml
use_default_settings: true

general:
  debug: false
  instance_name: "umr-searxng"        # 自定义实例名

search:
  safe_search: 1
  autocomplete: ""
  default_lang: "zh-HK"               # 中文默认 locale：香港
  formats:
    - html
    - json

outgoing:
  request_timeout: 5.0
  proxies:
    all://:
      - http://127.0.0.1:7897        # 本机走 mihomo 代理；VPS(docker) 用 http://172.17.0.1:7897

server:
  port: 8888                          # 本机 8888；VPS(docker 内) 8080
  bind_address: "127.0.0.1"
  secret_key: "ultrasecretkey"        # ⚠️ 生产环境务必改成强随机值
  limiter: false                      # 本地单用户 agent 后端，关闭限流
  public_instance: false
  image_proxy: false
  method: "POST"

valkey:
  url: false

ui:
  default_theme: simple

engines:
  # ✅ 高质量中文引擎
  - name: bilibili
    disabled: false
    categories: [videos, general]

  - name: tavily                    # 核心：Tavily API 引擎
    engine: tavily
    shortcut: tvy
    api_key: "tvly-REPLACE_WITH_YOUR_KEY"   # ⚠️ 填真实 key
    page_size: 10
    search_depth: basic
    topic: general
    categories: [general, web]
    disabled: false

  # ✅ 可用补充引擎
  - name: google
    disabled: false
    inactive: false

  - name: yandex
    disabled: false

  - name: mojeek
    disabled: false
  - name: mojeek images
    disabled: false
  - name: mojeek news
    disabled: false

  - name: marginalia
    disabled: false
    inactive: false

  # ❌ 禁用：低信誉 IP 返回降级垃圾 / 乱码（实测污染搜索结果）
  - name: bing
    disabled: true
    base_url: https://cn.bing.com

  - name: seznam
    disabled: true

  - name: qwant
    disabled: true
```

### 引擎选择说明

| 引擎 | 状态 | 原因 |
|---|---|---|
| **tavily** | ✅ 启用 | 核心引擎，API 不受 IP 影响，中文质量最高 |
| bilibili | ✅ 启用 | 中文视频/社区内容优质 |
| google | ✅ 启用 | 网页爬取，国内 IP 偶尔可用（CAPTCHA 时自行降级） |
| yandex / mojeek / marginalia | ✅ 启用 | 补充广度 |
| **bing** | ❌ 禁用 | 对本机 IP 返回降级垃圾页（Windows 帮助/无关首页） |
| **seznam / qwant** | ❌ 禁用 | 低信誉兜底引擎，返回乱码爬虫站 |

## 3. 网关配置（agent_search_gateway/gateway.yaml）

完整配置（含 browser/fetch/ad_filter 等全部项），复制即用。基于本机实测调优。

```yaml
# agent_search_gateway 网关配置（整体 yaml）
# token 建议用环境变量 GATEWAY_TOKEN 注入，避免写文件：
#   export GATEWAY_TOKEN=your-secret
# 留空 = 不认证

gateway:
  host: 127.0.0.1
  port: 3000
  token: ""

logging:
  level: info          # debug | info | warn | error
  file: ""             # 空=输出到 stdout，否则写文件

searxng:
  url: http://127.0.0.1:8888
  timeout_ms: 20000    # 需大于 searxng 内部 max_request_timeout(15s)，
                       # 否则引擎超时等待期间网关先 abort → 稳定 SEARCH_TIMEOUT

flaresolverr:
  url: http://127.0.0.1:8192
  enabled: true            # 路由②（CF/JS 渲染）总开关
  timeout_ms: 60000        # FlareSolverr 请求超时
  max_concurrent: 2        # 并发信号量（保护浏览器资源）
  trigger_status: [403, 405, 429]   # direct 这些状态 → 升级 FlareSolverr
  fallback_on_empty: true  # direct 200 但空壳 JS → 升级

search:
  max_results: 10
  max_result_chars: 500
  cache_ttl_ms: 300000    # 5 分钟
  cache_max_entries: 200
  max_concurrent: 2       # 搜索并发信号量

rerank:
  enabled: true
  # 轻量重排层：绕过 searxng 的 category 分组排序，按「score × boost」降序重排。
  # key 用 searxng 注册名（JSON engine 字段），非 settings.yml 的 name；
  # 默认 1.0，不配 = 按原始 score 排序。
  engine_boost:
    tavily: 1.2           # ⭐ 核心：Tavily 质量高，加权置顶
    bilibili: 1.2         # 中文视频社区优质
    "google cse": 1.0
    wikipedia: 1.0
    github: 1.0
    stackoverflow: 1.0
    reddit: 1.0
    news: 1.0
    # bing / duckduckgo / brave 已禁用，无需 boost（避免残留引用）

ad_filter:
  enabled: true
  # off | ads | ads+tracking | full
  level: ads
  extra_domains: []        # 额外屏蔽域名（追加到 hosts 之上）
  hosts_file: data/adblock/hosts
  auto_update: true        # 启动时若 hosts 缺失/过期自动拉取
  auto_update_interval_ms: 86400000   # 过期阈值 24h
  # 保白名单：这些域名即使命中黑名单也保留（防误杀）
  allowlist:
    - wikipedia.org
    - github.com
    - github.io
    - githubusercontent.com
    - stackoverflow.com
    - stackexchange.com
    - reddit.com
    - youtube.com
    - google.com
    - bing.com

fetch:
  timeout_ms: 15000
  max_bytes: 5242880       # 响应体上限 5MB
  user_agent: ""           # 空=默认 Chrome UA
  block_private_ips: true  # SSRF 防护
  private_ip_exempt_cidrs:  # 命中视为非私有（默认豁免 Clash fake-ip 段）
    - 198.18.0.0/15
    - fdfe:dcba:9876::/64
  structural: clean        # clean(默认去导航/广告) | full(保留完整结构)
  max_output_chars: 20000  # 输出 md 上限
  cache_ttl_ms: 600000     # fetch 结果缓存 10 分钟
  cache_max_entries: 200

browser:
  enabled: true            # 浏览器能力（fetch 路由③ + browser_* 工具）
  headless: true
  pool_size: 1             # 实例池上限
  idle_ttl_ms: 360000      # 空闲 360s 自动关闭（可配）
  timeout_ms: 30000
  max_concurrent: 2
  engine: chromium         # chromium | camoufox（camoufox 预留）
  proxy_server: ""         # 代理预留
  proxy_username: ""
  proxy_password: ""
  wait_for_selector: ""    # 渲染前等待该选择器（复杂 SPA）
  screenshot:
    enabled: true
    max_size: 512          # 截图最大边长像素（可配）
    image_type: jpeg
```

### 网关配置调优说明

| 项 | 推荐值 | 说明 |
|---|---|---|
| `searxng.timeout_ms` | **20000** | 必须 > searxng 内部 max_request_timeout(15s)，否则稳定 SEARCH_TIMEOUT |
| `rerank.engine_boost.tavily` | **1.2** | ⭐ 新增：Tavily 质量高，加权让其置顶 |
| `rerank.engine_boost.bing/ddg/brave` | 移除 | 这些引擎已禁用，无需 boost |
| 其余 | 默认 | 与 gateway.yaml.example 一致 |

## 4. 部署差异表（本机 vs VPS）

| 配置项 | 本机（源码 + systemd） | VPS（docker） |
|---|---|---|
| searxng 地址 | `http://127.0.0.1:8888` | `http://127.0.0.1:8890` |
| flaresolverr 地址 | `http://127.0.0.1:8192` | `http://127.0.0.1:8191` |
| 代理地址 | `http://127.0.0.1:7897` | `http://172.17.0.1:7897`（docker bridge） |
| settings.yml 位置 | `~/Projects/searxng/settings.yml` | `/etc/agent-search/settings.yml`（bind mount） |
| 引擎目录 | `searx/engines/` | `/etc/agent-search/engines/`（volume 挂载，容器重建不丢） |
| secret_key | settings.yml 内 | docker 环境变量 `SEARXNG_SECRET` 注入 |
| tavily.py 放入 | 源码引擎目录 | 挂载目录（已含全量引擎 + tavily.py） |

**VPS 部署 Tavily 步骤摘要**（详见 `README.md`）：
1. 引擎目录整体复制到宿主机 `/etc/agent-search/engines/`（含 tavily.py）
2. 重建容器时挂载 `-v /etc/agent-search/engines:/usr/local/searxng/searx/engines:ro`
3. settings.yml 追加 tavily 块 + 禁用 bing，`docker restart searxng-main`
